# Front-end: Front inicial para proyectos.

## Descripción:
### FrontEnd básico con todo lo necesario para empezar un proyecto, cuenta con una LandingPage simple, inicio de sesión, un CRUD completo para usuarios.

Tecnologías: React, Tailwind, JavaScript, etc...


## Clonar y probar la aplicación.

#### Clona el repositorio.

```
git clone git@github.com:rvh2776/basic-front.git
```

#### Entra a la carpeta del proyecto.

```
cd basic-front
```

#### Instala las dependencias.

```
npm install
```

#### Renombrar el archivo: .env.example a .env
* En el mismo se encuentra la descripción de los datos necesarios que se deben configurar,
  para iniciar el proyecto.

#### Iniciar la aplicación.

```
npm run build

npm run dev
```
